# MORITURI 스프라이트 규격 (M4-b)

뷰어(`viewer.html`)는 이 폴더에 `sprites.json` + 시트 PNG가 있으면 실루엣 대신 그림을 그린다.
없으면 조용히 실루엣 폴백. → **실제 그림은 이 규격만 맞추면 드롭인 교체.**

## 필요한 8포즈 (1v1 전투용)
횡스크롤 튜토리얼의 "걷기/점프"가 아니라, MORITURI 전투 상태에 맞춘 포즈다.

| 포즈 | 매핑되는 전투 상태 | 그림 |
|---|---|---|
| `idle`   | Idle | 대기 자세 |
| `walk`   | Move, Dodge | 전진/이동 |
| `windup` | Windup | 무기 치켜듦(선딜) |
| `strike` | Active, Recovery | 무기 뻗음(타격) |
| `guard`  | Guard | 방패/막기 |
| `hurt`   | HitStun, Stagger | 피격·휘청 |
| `down`   | Down, GetUp | 넘어짐 |
| `taunt`  | Taunt | 도발(팔 올림) |

## 시트 규격
- **방향:** 전부 **오른쪽 향함**. 왼쪽은 코드가 좌우 반전.
- **앵커:** 발이 프레임 **하단**에 닿게(바닥 기준). 화면 키 ≈ 78px로 스케일됨.
- **배경:** 투명(remove.bg 후).
- 기본 레이아웃: 96×96 한 칸, **가로 1줄 × 8칸**(= 768×96). 순서 = 위 표 순서.

## 추후.odt 파이프라인 적용
1. 제미나이로 프롬프트 생성 → 나노바나나로 **스프라이트 시트** 생성
   (프롬프트에 위 8포즈·오른쪽 향함·투명/흰배경·일관된 크기를 명시).
2. `remove.bg`로 배경 투명화.
3. (프레임이 불규칙하면) **Leshy SpriteSheet Tool**로 각 포즈 좌표 추출 →
   `sprites.json`의 `frames` 좌표(x,y,w,h)를 그 값으로 교체.
   규칙적 96×96 그리드면 좌표 그대로 둬도 됨.
4. 시트 PNG를 `gladiator.png`로 저장(또는 `sprites.json`의 `image`를 파일명에 맞춤).
5. 브라우저 새로고침 → 끝.

## 현재 파일
- `gladiator.png` — **플레이스홀더**(코드 생성, 파이프라인 검증용). 진짜 그림으로 교체할 것.
- `sprites.json` — 프레임 좌표 매핑.

## 확장 (나중)
- 무기별 시트: `sprites.json`을 무기 ID별로 분기(`WPN_SWORD.png` 등) → 선수마다 다른 외형.
- 걷기/공격 다중 프레임 애니메이션(포즈당 N프레임 + 시간 보간).
